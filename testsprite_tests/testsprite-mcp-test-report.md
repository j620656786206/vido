1. **🔴 真 bug：媒體庫「掃描排程」從來沒存成功過**（`bugfix-scan-schedule-field-mismatch`，P1）。前端送／讀 `frequency`，後端只認 `interval`。本機 Playwright 實測：選「每天」→ `PUT /scanner/schedule {"frequency":"daily"}` 回 400、選單仍是「僅手動」、重新整理仍是「僅手動」，而且錯誤訊息是英文。
   - **TestSprite 在這條上不可靠**：TC068／TC136 共 6 次裡 4 次判 PASS。查生成的程式碼，它寫出 `select_option("")`（選空值）又沒有最後的斷言，於是空洞地通過。以後這類「下拉選單＋持久化」的案例，PASS 也要用本機實測核對。

3. **TC123（日誌篩到空）偶發失敗**：7 次 2 次。程式與 API 直測都正常，失敗時是按 Enter 後太早檢查，屬測試時機問題。
