# 匿名使用回報（使用者自選開啟）

[English](usage-report.md)

Vido 可以每週送一份很小的匿名計數給維護者，讓他知道 Vido 是不是真的有人在依賴。**預設是關閉的**，你沒打開就不會送。

## 會送什麼

開啟期間，最多每 7 天送一次：

| 欄位                    | 範例                                   | 是什麼                                                                                                       |
| ----------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `id`                    | `3f2a6c1e-8f0b-4d5e-9a7c-1b2c3d4e5f60` | 你第一次打開時隨機產生的編號。不是從你的硬體、帳號、網路或任何東西算出來的；每週都一樣，所以同一台只算一次。 |
| `version`               | `0.1.2`                                | 你用的 Vido 版本。                                                                                           |
| `subtitles_auto_7d`     | `7`                                    | 最近 7 天 Vido **自己**做出來的字幕數（掃描之後、或下載完成之後）。你自己按下去產生的不算。                  |
| `subtitles_embedded_7d` | `4`                                    | 其中來自影片裡本來就有的字幕軌。                                                                             |
| `subtitles_online_7d`   | `2`                                    | 其中來自線上字幕來源。                                                                                       |
| `subtitles_asr_7d`      | `1`                                    | 其中來自語音辨識。                                                                                           |

其他欄位是接收端需要的固定值，每一台 Vido 都一樣：`website`、`hostname`（`vido`）、`url`（`/usage-report`）、`name`（`weekly_usage`），以及 `ip` 固定填 `127.0.0.1`，請接收端不要查你的國家（目前版本的 Umami 收到它就會跳過國家查詢；維護者在開始收資料前，會先在接收端實測確認）。

一份完整的回報就長這樣：

```text
{"type":"event","payload":{"website":"11111111-2222-3333-4444-555555555555","hostname":"vido","url":"/usage-report","name":"weekly_usage","id":"3f2a6c1e-8f0b-4d5e-9a7c-1b2c3d4e5f60","ip":"127.0.0.1","data":{"version":"0.1.2","subtitles_auto_7d":7,"subtitles_embedded_7d":4,"subtitles_online_7d":2,"subtitles_asr_7d":1}}}
```

設定頁會一字不漏顯示上一次真的送出去的內容，以及送出的時間。

## 絕對不送什麼

- 片名、檔名、資料夾路徑，或片庫的任何其他資料
- 你看了、想要、下載了什麼
- API 金鑰、密碼或任何其他設定
- 任何認得出你、你的 NAS 或你的網路的東西

## 怎麼開、怎麼關

> 下面這兩個開關會在下一版提供。在那之前，介面上還打不開這個功能；沒有設定接收端的版本也會顯示「不可用」。

- **首次設定精靈**會問一次，預選的答案是「關閉」。
- **設定頁**有開關，隨時可以改。關掉之後就不會再送；再打開會沿用同一個隨機編號。

## 送到哪裡、多久一次

- 送到維護者自架的 [Umami](https://umami.is) 統計服務。Umami 不保存 IP 位址。
- 最多每 7 天一次。送失敗的話，Vido 會等滿 7 天才再試；失敗不會跳出錯誤，也不會影響任何其他功能。
- 從原始碼自己編譯的版本（以及 fork）沒有設定接收端，所以這個功能在那裡不能用。
