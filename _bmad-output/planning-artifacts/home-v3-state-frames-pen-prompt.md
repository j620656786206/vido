## 1. `H4-D-v3 · 首頁 v3（載入骨架）` — x=21850 y=45300

整頁載入中的樣子。由上而下：

- **讀數帶骨架**：一條與 H1-D-v3 讀數帶等高的圓角橫條（`#132320`），內部**不畫
  任何文字或分隔線**——量不到的東西不能先畫出來假裝有。
- **Hero 骨架**：400 高的整塊 `#132320` 圓角矩形，內部空白。
- **「最近新增」骨架**：標題位置放一個 120×20 的 `#132320` 小條（代表標題），
  下方 6 張海報骨架（比例 2:3、圓角 12），每張下方兩條文字骨架（寬 80% 的
  `#132320` 與寬 40% 的 `#1b302b`）。
- **TMDb 區骨架**：同上再一排 6 張。
- 註記文字（放在 frame 內容欄最下方，`#8fa096` 12px）：
  「每一區各自載入、各自失敗；此稿只描述全部同時在載入的最壞情況。」

## 2. `H5-D-v3 · 首頁 v3（空片庫・首跑）` — x=23410 y=45300

**這是新使用者看到的第一個畫面**，v2 從來沒畫過，實作時是照 brief 推導的。
由上而下：

- **讀數帶（真的有數字，不是骨架）**：四格照 H1-D-v3 的樣式，但內容為
  1. 繁中字幕 · 開始掃描 → `0/0`（整格是一扇門，指向掃描設定）
  2. 今天處理 → `0 部`
  3. 需要注意 → `一切正常`（**維持一般文字色，不可用琥珀**——沒有例外就不是例外）
  4. 進行中 → `0 個任務`
  第 1 格請在標籤處明確畫出「繁中字幕 · 開始掃描」兩段文字，讓它看得出是門。
- **Hero：整段不存在**（不要畫空框、不要畫佔位）。讀數帶下面直接接「最近新增」。
- **「最近新增」**：標題照常，下方只有一行弱色文字「尚無最近新增」。
- **TMDb 區照常有內容**（探索不依賴你的片庫）：標題「熱門電影」＋說明字幕
  「已擁有的作品不會出現這裡」＋ 6 張正常海報卡。
- 註記文字（`#8fa096` 12px）：
  「片庫為 0 時 hero 不渲染（例外訊號原則）；覆蓋率 0/0 是資訊不是錯誤，
  該格改為「開始掃描」的門。」

## 3. `H6-D-v3 · 首頁 v3（自家內容載入失敗）` — x=24970 y=45300

**這張要記錄一個真實的耦合**：hero 與「最近新增」吃的是**同一個查詢**
（`useRecentlyAdded`），所以那個查詢失敗時，**hero 會一起消失**。由上而下：

- **讀數帶照常有數字**（它走不同的 API，不受影響）：42/55 · 3 部 ·
  2 部失敗 · $1.2/$5（琥珀）· 2 個任務。
- **Hero：整段不存在**（與 H5 相同的缺席畫法）。
- **「最近新增」錯誤橫幅**：整寬圓角矩形，底色 `#c0392b1f`，左側 `triangle-alert`
  圖示＋文字「無法載入，請稍後再試」（色 `#e08a76`），右側「重試」按鈕
  （文字色 `#e08a76`，高度看起來要有 44）。
- **TMDb 區照常有內容**（它是另一個 API，不受影響）。
- 註記文字（`#8fa096` 12px）：
  「hero 與最近新增共用同一個查詢：該查詢失敗時 hero 一併缺席，錯誤只由
  最近新增這一條橫幅說一次，不重複報。TMDb 側的失敗另見 H7-D-v3。」

## Schema 注意（與前兩份提示詞相同）

- 對齊 enum 只有 `start` / `center` / `end`，**沒有** stretch／flex-*
- `fill_container` 的 text 要設 `textGrowth`
- Color 只吃 hex（透明用 8 碼 `#RRGGBBAA`）
- 圖示名用 Pencil 版 lucide：警示三角是 `triangle-alert`（不是 alert-triangle）
- 根框架用 horizontal layout（側欄在左、內容在右），內容欄本身 vertical
