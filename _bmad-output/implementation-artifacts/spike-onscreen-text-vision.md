官方中文 `See.S01E02…zh-TW.srt` 有 5 句括號說明。對齊到本機影片（官方 −51.7 秒）後逐一截圖確認：

**考題 4 題。**

## 及格線（開跑前寫定，跑完不改）

1. **抓到：4 題至少 3 題**——時間差 ±5 秒內、意思對（書名、「三年後」）。
2. **多抓：整集「不該翻卻翻了」最多 5 處**——片頭片尾名單、公司 logo、背景裡看不清或無意義的字都算錯；官方沒翻、但確實是劇情相關的字（例如紙條、招牌）另外列出，不算錯，給 Alexyu 判斷。
3. **錢：一集 ≤ US$1.00**（這集翻譯本身 US$0.35）。
4. **做得到：只用 ffmpeg＋一個 API 呼叫的方式**——正式機（Docker、沒有 GPU、沒有本機 OCR）也能跑。

## 做法

- ffmpeg 每 2 秒取一格，縮成寬 512，**3×3 拼成一張圖**（約 1,710 格 → 190 張圖）。每張圖附上 9 格各自的時間。
- 模型：預設 `claude-opus-5-5`（Anthropic 目前預設的模型；不為了省錢自行換小模型）。結構化輸出（JSON schema）：每處畫面字回報格子編號、英文原文、類型（字卡／書／招牌／紙條／名單／logo／其他）、要不要翻、繁中翻譯。
- 後處理：同一段文字連續出現的格子合併成一處；和考卷比對；用 API 回報的 token 數算錢。
- 第一輪跑下來發現 512 寬的小格看不清書名，所以加了第二步：模型若說「這格有字但看不清」（書、紙、招牌），就把那一格原尺寸截圖再看一次。
- 程式放 `scripts/onscreen-text-spike.py`（Python＋官方 `anthropic` SDK，跑在 scratchpad 的 venv）。**逐句結果不進 git**（repo 是公開的，`feedback_public_repo_no_transcripts.md`），只記數字。

## 結果（2026-10-08，`claude-opus-5-5`，effort low）

**判定：不及格**（第 1 條勉強、第 3 條沒過）。

| 及格線 | 結果 | 判定 |
|---|---|---|
| 1. 4 題抓到 ≥ 3 | 「3 YEARS LATER」→ 三年後（35:40）✅；*To Kill a Mockingbird* → **梅岡城故事**（55:06，台灣通行書名；官方寫的是港陸譯名）✅；「ABC」看到了（15:54）但模型判成「不用翻」❌；*1984* **漏掉** ❌ → **2/4** | ❌ |
| 2. 不該翻卻翻了 ≤ 5 | 片頭片尾名單 64 處、logo 4 處**全部正確判成不用翻**。標成要翻、官方沒翻的 5 處：ABC 課本內頁的 RABBIT／FOX（兩處，同一頁算兩次是合併的問題）、Shakespeare（書）、封面小字「Pulitzer Prize Novel」。真的錯的只有封面小字 1 處；其他是劇情裡的書，給 Alexyu 判斷 | ✅ |

**1984 為什麼漏掉：是實驗程式的 bug，不是模型看不到。** 程式把「同一個鏡頭」只放大看一次：55:06 那格看到《梅岡城故事》，55:08 那格就被跳過，而 *1984* 要到 55:08 才看得清。單獨把 55:08 原尺寸丟給模型，它讀出「George Orwell 1984 → 喬治·歐威爾《一九八四》」（US$0.01）。程式已改成每個被點名的格子都看一次；**整集沒有重跑**（再花 US$2.3），所以修正後的分數推估是 3/4、但沒有實測。

**也確認了：「有外人在此」不是畫面字。** 那是角色用手勢溝通、英文字幕軌本來就有的一句，Vido 新版 18:53 已翻成「我們並不孤單」。

### 學到的

- **方向是可行的**：會看圖的模型能分清「劇情要讀的字」和「名單、logo」，時間卡、書名都讀得出來，還會用台灣通行書名。
- **小字要放大看**：拼圖只夠找出「哪裡有字」，書名要原尺寸才讀得到。
- **錢是卡關的地方**：大部分花在掃 190 張拼圖。可以省的地方（都沒試）：取樣改 3 秒一格（約省 1/3）、跳過片頭片尾名單（省得不多）、換較便宜的模型（Sonnet 5.5 價格是一半、Haiku 4.5 是四分之一，但辨識品質要另外測）。**換模型是 Alexyu 的決定**，所以這次沒有自己換。

## 第三輪（2026-10-08，Alexyu 選 A）

**開跑前的變更（Alexyu 裁定，跑之前寫下）**

- **ABC 不算考題**（官方那句是譯者說明，不是翻字）。考題剩 3 題：三年後、《梅岡城故事》、《一九八四》。第 1 條改成「**3 題全中**」（原本 4 中 3 = 75%，少一題後不降標準）。其他三條不變。
- **Alexyu 的疑慮**：其他影集畫面上是**人名或地名**時（地名字卡、招牌上的店名），模型會不會也像 ABC 一樣判成「不用翻」？這輪改兩件事：
  1. **要不要翻改由「類型」決定，不聽模型的感覺**：字卡、書、招牌、紙條、螢幕一律算要翻；只有片頭片尾名單、公司 logo、浮水印不翻。`needs_translation` 只留作紀錄。
  2. 提示詞明講：畫面上的人名、地名、組織名照樣要翻，用台灣字幕的音譯慣例；之後接進正式功能時，會先查這部片的名詞表（跟對白用同一套譯名）。
- 這集沒有人名地名字卡可以考，所以第 2 點這輪只能看「有沒有亂翻」，**真正的考驗要另一部有地名字卡的片**（記在結果裡）。

**演算法的變更**

- 取樣改成 3 秒一格（張數再少約 1/3）。
- 放大看的那張改成寬 1280（原尺寸 1920 的 token 約一半；書名在 1280 寬仍讀得到）。
- 放大時，請模型列出畫面上**所有**看得到的字，不只一樣。
- 被點名的格子，連同它**前一格**一起放大（補上第二輪「去重跳掉 55:06」那種漏法）。

**第三輪結果**（US$0.82：輸入 18.7 萬 token、輸出 3,784；1,139 格 → 去重後 870 格 → 55 張拼圖＋29 張放大）

| 2. 不該翻卻翻了 ≤ 5 | ✅ 名單／logo 21 處正確不翻。照「類型」規則被列為要翻的：ABC 課本上的單字母 B／C（4 處，譯文跟原文一樣，正式功能會濾掉）、RABBIT → 兔子、封面小字「Pulitzer Prize Winner」→ 1 處真的不該翻 |
| 3. 一集 ≤ US$1.00 | **US$0.82 ✅** |
| 4. 正式機做得到 | ✅ |

**判定：第三輪仍不及格（只差第 1 條）。**

**《一九八四》為什麼漏**：兩本書是兩個人輪流舉起來的，《一九八四》大約只在 55:07～55:09 看得清。3 秒取一格時，拼圖只點名 55:06 那格要放大；「連前一格一起放大」補不到後面那一格。三輪各漏的那一題，原因都一樣：**字只出現兩三秒，剛好落在沒被放大的那一格**。

**三輪合起來的結論**

- 每一題都至少在一輪被讀對；名單／logo 三輪都沒亂翻；台灣書名都對。**模型的辨識不是問題，問題在「哪幾格要放大」。**
- 錢已經壓到 US$0.82。剩下能做的：被點名的格子前後各一格都放大（推估多 US$0.1 左右，總共約 US$0.9），或在被點名的鏡頭裡每秒放大一張。
- **人名／地名**（Alexyu 的疑慮）：規則已改成「字卡、招牌一律翻，名字用音譯」，這集沒有這種題目，**還沒驗證**。需要一部有地名字卡的片來考（例如諜報片常見的「德黑蘭，伊朗」字卡）。
