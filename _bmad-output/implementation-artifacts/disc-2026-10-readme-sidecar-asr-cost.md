2. **聽寫服務。** 「聽聲音生字幕」那條改成：預設用 ElevenLabs Scribe（填了金鑰的話），也可以用 OpenAI Whisper 或自架的相容服務。
3. **價錢表。** 「沒有字幕、要先聽聲音」那一列換成正式機實測的數字（一集約一小時、預設翻譯模型）；註明量測日期。不寫片名（repo 是公開的）。
4. **看內容判斷繁簡。** 「跟 Bazarr／Lingarr 差在哪」補一條：中文字幕是繁體還是簡體，看字幕內容判斷，不信檔名或標籤。對手的部分不寫成「它做不到」，只寫 Vido 怎麼做。

6. 開頭的英文段落跟著中文一起改（Bilingual Docs Rule）。
7. `prettier --check README.md` 通過。
