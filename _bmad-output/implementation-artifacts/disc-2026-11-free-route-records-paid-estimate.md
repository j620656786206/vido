# Story disc-2026-11-free-route-records-paid-estimate：花費明細的「預估準度」不再被免費的片拉低

Status: done

**Source:** sprint-status 同名待辦（P2，PR #946 建單）。⚖️ Alexyu 2026-11-01「處理剩餘的4項代辦」。

## 問題

《基地》S1E1、E2 走「直接用片內繁中」，實際 $0，卻記了預估 $0.32、$0.29。明細頁的「預估準度」因此從 105% 被拉低成 79%，看起來像預估很不準。

原因：預估是開跑時算的，用的是跟確認視窗同一套報價（`subtitle/predict_route.go`）。報價只分「要不要語音辨識」：片內有中文或英文文字軌都算 `extract`，照翻譯的價格報。這是刻意的設計——中文軌要真的抽出來看內容，才知道是繁體、簡體還是標錯語言，報價寧可報高，不能報低。

## 決定（Bob）

待辦列了兩條路：

- (a) 路線確定是免費線時，把預估改成 0。
- (b) 準度只算有花錢的路線。

選 **(b)**。預估欄位記的是「按下去之前看到的報價」，這是事實，不該事後改掉；要修正的是準度把不該比的也拿來比。每一筆的「預估 $0.32／實際 $0.00」照常顯示，那也是事實。
