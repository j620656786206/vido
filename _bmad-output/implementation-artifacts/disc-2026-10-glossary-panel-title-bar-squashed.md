# Disc：名詞對照表詞一多，標題列就被壓扁、✕ 掉到分隔線下面

Status: in-progress

**Source:** 2026-10-18 Alexyu 在正式機看《末日光明》（See）的名詞對照表（115 條）：「名詞對照表的 UI 跟設計稿好像有所出入，請修改畫面對齊設計稿；如果設計稿需要調整，再請 Designer 修。」

## 查到的事

- 正式機用 Playwright 量（1440×820）：標題列 `glossary-title-bar` 只有 **26px**，設計稿 F6-D-v2（`dlfMR`）是 56px。標題貼著面板頂、分隔線緊貼標題，✕（`top-4`，絕對定位）掉到分隔線下面。
- 根因：面板是 `flex-col` + `max-h-[85vh]`，高度不是定值，所以清單區的 `flex-1`（basis 0%）被當成內容高度算；清單一長，溢出量按 basis 比例分給每個子項縮。標題列只有 `h-14`、沒有 padding，就一路縮到文字高度。頁尾有 padding 撐著，看不出來。
- 畫廊的視覺夾具只有 3 條詞，清單沒溢出，所以視覺回歸一直沒抓到。
- 打開面板時焦點落在「全部確認」（Radix 預設聚焦第一個可聚焦元素），畫面上多一圈焦點框（設計稿沒有）。更要緊的是：這時按一下 Enter 就把 110 條未確認的詞全部確認了。

## 範圍

1. 標題列、頁尾不准縮（`shrink-0`），只有清單區捲動。
2. 打開面板時焦點放在面板本身，不放在「全部確認」。
3. 畫廊加一個長清單夾具（40 條），讓視覺回歸抓得到這類問題。

## 不做

- 季別徽章 `S1`／`S2` 與「官方字幕」來源徽章補進 `.pen`：設計稿缺口，交給 Sally（另開）。
- 同一個詞多季多列的呈現方式：等 Alexyu 對「每季照官方 vs 全劇統一」的裁定。

## Acceptance Criteria

1. 115 條詞的面板：標題列 56px、✕ 在標題列裡；頁尾高度不變；清單區自己捲動。
2. 打開面板後 `document.activeElement` 是面板容器，不是「全部確認」；Tab 一次到第一顆按鈕。
3. GlossaryPanelV2 spec 鎖住兩件事；畫廊長清單夾具存在。
4. web spec、lint:all、typecheck 全綠。
