## Sally 的設計決定

### 入口

- 活動頁「本月 AI 花費」卡片（`SpendCard`）右下角加文字連結「看明細 →」，連到 `/activity/spend`。月份沒有任何紀錄時卡片本來就不顯示，入口跟著不顯示。

### 頁面 `/activity/spend`「AI 花費明細」

由上到下：

1. **標題列**：「← 活動」返回連結＋標題「AI 花費明細」。右邊是月份切換「‹ 2026 年 11 月 ›」，預設本月，不能切到未來。
2. **摘要列**（沿用 `SpendCard` 的 `LaneStat` 樣式，`dl` 橫排、手機直排）：
   - 這個月總共花多少、跑了幾次
   - 預估準度：只算「實際和預估都有記」的那幾筆，顯示「實際是預估的 N%」。一筆都沒有時寫「還沒有可比的紀錄」。
3. **圖表**：每日堆疊長條，一天一根，依處理方式分顏色（四類，見下表）。不加新套件，用 inline SVG＋既有色票 token。
   - 桌機：滑過長條時顯示當天合計和各類金額。手機：點長條顯示同樣內容。
   - 沒花錢的日子畫高度 0 的底線，不是空白。
   - 下方圖例，跟顏色一一對應。
4. **逐筆列表**：最新的在最上面，一次 50 筆，底下「載入更多」。
   - 桌機是表格：時間、影片、處理方式、用了哪些模型、實際、預估、狀態。
   - 手機是卡片：第一行影片名＋實際金額，第二行時間・處理方式，第三行模型；預估和狀態放第四行。
   - 篩選：處理方式 chip（全部／四類），放在列表上方。

### 處理方式的名稱（畫面上的字）

| 圖表分類 | 列表上的字 | 來源（route／source） |
|---|---|---|
| 片內中文字幕 | 直接用片內繁中 | `deliver_direct` |
| 片內中文字幕 | 片內簡中轉繁體 | `convert_then_deliver` |
| 翻譯英文字幕 | 翻譯片內英文字幕 | `translate`＋`embedded_text` |
| 翻譯英文字幕 | 翻譯片旁英文字幕 | `translate`＋`sidecar` |
| 翻譯英文字幕 | 翻譯英文字幕 | `translate`＋來源沒記（舊資料） |
| 語音辨識＋翻譯 | 語音辨識＋翻譯 | `asr` |
| 舊紀錄 | 舊紀錄（沒分類） | 路線沒記（9 月的 24 筆） |
| （不進圖表） | 沒有可用字幕 | `no_text_source`、`skip` |

「語音辨識」沿用活動頁既有用詞（`SpendCard` 的 LaneStat），不用「聽寫」。

### 誠實規則（PRODUCT.md 原則 1）

- 沒記到的數字寫「沒記錄」（`--text-muted`），**絕不顯示 US$0.00**。真的花 0 元的（例如直接用片內繁中）照實寫 US$0.00。
- 實際比預估高超過 50% 時，實際金額旁加 ⚠ 和「比預估高 N%」。
- 失敗、中途停止的執行照列，狀態欄寫「失敗」「中途停止」，花的錢照算進合計和圖表。
- 模型：有翻譯時列翻譯模型（`font-mono`），有語音辨識時再列引擎和模型（例如「ElevenLabs scribe_v2」）；都沒有就寫「—」。

### 狀態

- 載入中：摘要、圖表、列表各一塊 skeleton（沿用 `ActivityStates`）。
- 這個月沒有任何紀錄：「這個月還沒有生成過字幕」＋返回活動頁的連結。
- 載入失敗：fail-soft，「無法載入」＋「重試」（沿用 `ActivitySectionShell` 的寫法）。
