# disc-2026-11-burned-in-subs-c：畫面怎麼顯示「燒在畫面上的字幕」（Sally 設計決定）

**Source:** 傘狀 `disc-2026-11-burned-in-subs`；⚖️ Alexyu 2026-11-02「接著做」。Pencil 轉付費後的做法（2026-11-01 裁定）：不出 .pen 稿，照現有 design system 做，設計決定寫在這裡，UX 驗證對照現有元件截圖。

## 用字

- 來源名稱：**畫面字幕**（不寫「燒錄」「硬字幕」等術語）。
- 說明：**燒在畫面上，不能關掉**。

## 出現在哪裡

1. **季清單的字幕圖示提示框**（`EpisodeList` 第二行「來源」）：來源清單多一種「畫面字幕」，跟「片內字幕・旁邊的 zh-TW 檔・Vido 生成」同一串、同一種寫法。圖示與顏色規則不變——它跟其他來源一樣只是「有中文」的來源之一。
   - **例外（2026-11-02 補）**：判斷是 `zh_hans`、而且中文來源**只有**畫面字幕時，不用紅色「只有簡中字幕，可以在管理字幕轉成繁中」（燒在畫面上的字不能轉，2A 也說它算有中文），改成綠色勾「**有簡中字幕（燒在畫面上）**」，第二行列來源。
2. **管理字幕彈窗「現有字幕」**（`ManageSubtitleDialogV2`）：多一列，樣式與其他列相同。
   - 左邊語言徽章：`zh-Hans`→簡中、`zh-Hant`→繁中、`zh`→中文（同既有徽章顏色）。
   - 來源：畫面字幕；細節：燒在畫面上，不能關掉。
   - 列尾一個文字按鈕「**判斷錯了？**」（`--text-secondary`、44px 觸控高度），點開兩個選項：
     - 「**這季沒有畫面字幕**」：整季改成沒有，立即生效。
     - 「**重新檢查這季**」：馬上再看一次（會花約 US$0.002，選項下面用小字寫出來）。
   - 檢查結果是「沒有」或還沒檢查時，不出現這一列。
3. **生成字幕按鈕下方**（同一個彈窗）：這集有畫面字幕時，按鈕照常可以按，按鈕下方多一行小字（`--text-muted`）：「**畫面上已經有中文字幕，再生成的字幕會跟它疊在一起**」。
4. 片庫卡片、篩選：不改。判斷已經由後端算進 `chinese_subtitle`（-b1），卡片自然不再顯示缺中文。

## 不做

- 不新增顏色、不新增圖示。
- 「沒有畫面字幕」的集數不提供「改成有」：沒有入口，等使用者真的遇到再說。

- `-c1` 後端：集數 JSON 露出 `burned_in_subtitle`；季清單的中文來源多一種 `burned`；改判 API。
- `-c2` 前端：上面 1～3。
