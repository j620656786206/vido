# Story disc-2026-11-online-sub-download-progress：線上字幕下載的圈圈顯示進度；會蓋掉現有繁中字幕時先跳窗確認

Status: done

**Source:** ⚖️ Alexyu 2026-11-02 實測《天蠍行動》E02 下載射手網整季包：「按了下載，卻一直在轉圈中」（實際 31 秒成功）；而且蓋掉了原本 AI 生成的繁中字幕（有備份 .bak）。裁定：
1. **不要另外加一句說明**（介面會雜亂）→ 讓轉圈圈本身顯示下載進度。
2. 會取代現有繁中字幕時要提醒 → **下載前跳彈窗**。

## 做法

### 進度圈
- 後端下載流程本來就會用 SSE 發 `subtitle_progress`（downloading／converting／placing），但最久的一段（射手網：查詳細資料 → 單檔下載失敗 → 下載整包 → 解壓）在來源內部，沒有回報。
- 來源透過 context 回報進度（`providers.WithProgress`），射手網在每一步回報比例，整包下載時照已收到的位元組回報。
- 處理端把它換成 0–100 的 `percent` 放進 SSE（只加欄位，舊欄位不變）；轉繁 90、放檔 95。
- 前端：下載按鈕的圈圈改成「有進度就畫一圈填到幾成」，沒進度時維持原本的轉圈；不加任何文字，螢幕閱讀器讀 `aria-label`「下載中 40%」。

### 取代確認
- 現有字幕清單裡，若有一個影片旁的繁中字幕檔，檔名就是下載會寫入的名字（`<影片檔名>.zh-Hant.srt`／`.ass`）→ 按下載先跳確認窗。
- 文案：標題「要取代現有的繁中字幕嗎？」，說明「<檔名> 會被這份取代，舊的會另存成 .bak。」按鈕「取消」「取代」。
- 沒有會被蓋掉的檔案就直接下載，不跳窗。

## Acceptance Criteria

1. [x] SSE `subtitle_progress` 多 `percent`；射手網整包流程會一路回報（查詢、單檔、整包位元組、解壓、轉繁、放檔）。
2. [x] 下載中的圈圈依 `percent` 填滿；沒有 percent 時維持轉圈；不新增文字列。
3. [x] 會覆蓋同名繁中字幕時先跳確認窗；取消不下載；取代才下載。不會覆蓋就不跳。
4. [x] 測試；go／web 檢查全過；視覺基準若有變更則更新。
