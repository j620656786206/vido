# Story disc-2026-11-spend-history-mobile-table：AI 花費明細的逐筆紀錄，手機也用表格

Status: done

**Source:** ⚖️ Alexyu 2026-11-01 看手機截圖後說「逐筆紀錄應該換成表格呈現」；同日選「手機用精簡表格」（另一個選項是完整 7 欄、左右滑）。

## 問題

`/activity/spend` 的逐筆紀錄在電腦是 7 欄表格，在手機是一筆一張卡片（`disc-2026-11-spend-history-c` 的設計）。卡片一張四行，10 筆就要捲很長，而且金額散在每張卡片右上角，上下比不起來。

## 設計（Sally，取代 -c 的「手機是卡片」那一條）

- 手機（< md）也是表格，只顯示 4 欄：**影片｜實際｜預估｜狀態**。
- 時間、處理方式、模型不另開欄，用小字放在影片名下面：第二行「時間・處理方式」，第三行模型（多個模型用「＋」接在一起，可換行）。
- 電腦（≥ md）照舊 7 欄，影片名下面不顯示那兩行小字。
- 誠實規則不變：沒記錄、⚠ 比預估高 N%、失敗／中途停止照常顯示。
- 同一張表、用 CSS 斷點切欄，不再有手機專用的卡片。

## Acceptance Criteria

1. [ ] 手機寬度只看得到 影片／實際／預估／狀態 四個欄位標題；時間、處理方式、模型三欄在 < md 隱藏。
2. [ ] 手機上影片名下面有「時間・處理方式」和模型兩行小字；≥ md 隱藏。
3. [ ] 卡片列表移除；沒記錄／$0.00／⚠／失敗／中途停止的測試都對同一張表跑。
4. [ ] e2e（`tests/e2e/activity-spend.spec.ts`）在手機和桌機都找得到逐筆的列。
5. [ ] gallery 的手機 fixture 標籤改成表格；本機瀏覽器截手機寬度確認沒有橫向捲動。
