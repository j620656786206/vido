# Story disc-2026-11-opencc-zhi-misconverted：「還是只有」不會再被改成「還是隻有」

Status: done

**Source:** GitHub issue #939（Alexyu 2026-10-31，《Lioness》S01E01 01:51「是大家都知道還是隻有她知道」）。⚖️ Alexyu 2026-11-01 選 A：先修這個。不做：換 OpenCC 斷詞引擎（jieba）、翻譯選詞（asset／軍階／ASVAB，#940 的第 2 類）、聽寫錯誤（#940 的第 1 類）。

## 查到的事（2026-11-01，逐一實測）

### 錯字是誰改的

- 這集走「先聽寫再翻譯」（`subtitle_runs.route=asr`，10/28，Sonnet，US$0.52）。英文 "Does everybody know or just her?"，錯字出在最後的簡轉繁，不是模型。
- 本機 OpenCC 1.4.2（跟 Docker 映像同版，`apps/api/Dockerfile:16`）實測，`s2twp` 和 `s2tw` 都一樣：

| 輸入 | 輸出 |
|---|---|
| 还是只有 | 還是隻有 ❌ |
| 是只有她／是只要／是只能／是只会 | 是隻… ❌ |
| 最多只能 | 最多隻能 ❌ |
| 别只顾着 | 別隻顧著 ❌ |
| 還是只有（已經是繁體） | 還是隻有 ❌ |
| 也只有／都只有／就只有／只是／只好 | 不變 ✅ |

- 用 837 個常用字逐一放在「只有」前面測：OpenCC 會在 一二三…十百千萬、两、几、这、哪、每、别、是、多、有、单、换、大、小、整、首、半 後面把「只」當量詞。其中在對白裡常接副詞「只」的是：是、多（最多／頂多／至多）、別、有（沒有）、單（不單）。

### 影響範圍

- NAS 最近 60 天產生的 83 份 `.zh-Hant.srt`，9 份有錯（全部 176 行含「隻」的句子逐一看過）：不是隻有 ×6、最多隻能 ×2、還是隻想、還是隻有。三條路線都中：`asr`、`translate`、`convert_then_deliver`（官方簡中字幕轉繁體）。
- 其他「隻」都是對的量詞（那隻兔、一隻手、是隻狼、隻字）。

### 為什麼所有路線都會中

- 每一條送出中文字幕的路徑都呼叫 `zhtw.Finalize`（`internal/zhtw/finalize.go`），裡面先跑 OpenCC 再跑台灣詞庫。只要修 `Finalize`，全部路線一起修好。
- 翻譯快取存的是 `Finalize` **之前**的句子（`pipeline.go` `convertAndStitch` 每次重跑），所以不用動 `LexiconVersion`，不會讓已付費的翻譯快取失效。

## 設計

- 在 OpenCC 之前，把「讀起來是副詞的『只』」換成私用區字元 `U+E000`（OpenCC 不認得、原樣通過、也不影響旁邊的字），轉完再換回「只」。
- 「副詞的『只』」= 前面是 是／最多／頂多／至多／別／沒有／不單（簡繁都收），**而且**後面接的是動詞或副詞性的字（有、要、能、會、是、想、剩、在、顧……）。量詞後面接的是名詞（隻狗、隻手），不在名單內。
- 只防止 OpenCC 把「只」改成「隻」，**從不改輸入原本就有的「隻」**。所以模型寫對的繁體「那是隻會說話的鳥」不會被動。唯一用猜的是簡體輸入「是只会说话的鸟」，對白裡副詞用法遠多於這種量詞句。
- 輸入本身已經含 `U+E000` 時整段不處理，換回時不會憑空變出「只」。
- 不選的做法：
  - 轉完再把「隻有」改回「只有」：會把模型寫對的量詞句（「是隻有翅膀的鳥」）改壞。
  - 寫進台灣詞庫（`zh-tw.yaml` replacements）：詞庫只在「非陸港澳片」跑，`s2tw`（陸港澳片）一樣會出錯；而且這是字的轉換錯誤，不是用語問題。
  - 改用 OpenCC 的 jieba 斷詞：本機試過，「還是只有」對了，但「這是隻狗」變成「這是只狗」，而且要改 Docker 建置，影響所有轉換，範圍太大。

## Story

身為看 Vido 字幕的人，我希望「還是只有」「最多只能」這種句子照原樣顯示，不要變成「還是隻有」「最多隻能」。

## Acceptance Criteria

1. 簡體或繁體輸入的「还是只有她知道」「不是只有我们」「最多只能」「还是只想」「别只顾着」，經過 `Finalize`（`s2twp` 和 `s2tw` 兩種）後都是「只」。
2. 輸入原本就有的「隻」不變；「这是只狗」「抓到最多只的人」照 OpenCC 轉成「隻」。
3. 裝了真的 `opencc` 時，用真的 OpenCC 跑 AC 1、2 的代表句；沒裝就跳過。
4. 拿正式機兩份官方字幕（《泰德拉索》S01E07 片內簡中、繁中文字軌）整份跑一次，新舊結果只差在被修好的句子。
5. 不改翻譯快取的 key（`LexiconVersion`／`PromptVersion` 不動）。
