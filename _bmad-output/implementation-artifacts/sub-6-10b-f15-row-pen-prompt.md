## 三條裁定（推翻既有實作，程式碼要跟著改）

### 裁定 1 — 副標的 `≈` 拿掉

一列之內不得有兩個 `≈` 指不同的事。金額的 `≈` 意思是「這個數字建立在假設的片長上」；
副標的 `≈ 45 分` 意思是「不知道多長」。而且後者語意本身就錯：**45 分鐘不是約略量到的
片長，是一個假設** —— 約略是量測的誤差，假設是沒有量測。

- 片長未知 → 副標後段寫 **`片長未知（估 45 分）`**（陳述事實 + 括號裡放假設，無 `≈`）
- 片長已知 → 副標後段寫 `2 小時 46 分`（`formatRuntime` 的既有 zh-TW 形式）
- 金額 → 維持 `≈ $0.27`（只有片長是假設時才加）

結果：`≈` 每列最多出現一次，只有一個意思。

### 裁定 2 — 「未匹配」移到標題旁

右側徽章區原本混了四種不同性質的資訊。「未匹配」講的是**這列是什麼**（身分沒把握），
其餘三段講的是**這列會發生什麼**（能不能執行／哪條路線／多少錢）。不同級的東西不並排。

- 「未匹配」移入**身分欄**，緊接在標題右側：標題 `truncate`，徽章 `shrink-0`，
  標題再長也不會把它擠出畫面。
- 右側區留三段，左→右為 **狀態（資料夾無法寫入）→ 種類（抽取／語音辨識）→ 代價（金額）**。

懷疑要貼在被懷疑的東西旁邊；隔半個列寬的灰標，讀者不會把它連回標題。

### 裁定 3 — 無封面時的首字放大到 Title 階

`--text-muted` 12px 放在 `--bg-tertiary` 上是灰底灰字，做不到它唯一的任務
（讓第 47 列和第 48 列長得不一樣）。`--bg-tertiary` 是本系統已知的高風險底色。

- 首字改用 **Title 階（18px / 600）＋ `--text-secondary`**，於 38×54 灰塊內置中。
- ⚖️ 這是對 DESIGN.md「預設小字規則」的**刻意例外**，理由必須寫進 spec 註記：
  它不是文字標籤，是**海報的圖形替身**。
- 用既有 Title 階而非自創 16px，是為了不讓 `design-system-font-size` 偵測器多一個
  沒有授權來源的尺寸。

## 核定後的列版式（F15-D-v2 / F15-M-v2 共用）

```
┌──┬────────┬─────────────────────────────────────┬──────────────────────────────┐
│☑ │ 封面   │ 片名                    [未匹配]     │ [資料夾無法寫入] [路線] 金額 │
│  │ 38×54  │ 路線 · 片長                          │                              │
└──┴────────┴─────────────────────────────────────┴──────────────────────────────┘
   身分欄（identity）──────────────────────────────  狀態→種類→代價（job）
```

| 元素 | 規格 |
| --- | --- |
| 封面 | 38×54（2:3），`--radius-sm`；有海報＝實圖 `object-cover`；無海報＝`--bg-tertiary` 底 + 片名首字（18px/600/`--text-secondary`，置中） |
| 片名 | Body 14px `--text-primary`，`truncate`；未匹配時顯示解析後的乾淨片名，hover 顯示原始檔名 |
| 未匹配標 | Label 12px，`--bg-tertiary` 底 + `--text-muted` 字，`--radius-sm`；緊接片名右側，`shrink-0`；tooltip「TMDb 沒有比對到，片名由檔名解析」 |
| 副標 | Label 12px `--text-muted`，兩段以 ` · ` 並列：`路線 · 片長`。**兩段永不互相取代** |
| 資料夾無法寫入 | Label 12px，error tint 底 + `--error-text` 字；tooltip 帶資料夾名；整列 70% 透明、checkbox disabled |
| 路線徽章 | 抽取＝success tint／語音辨識＝warning tint（語意固定，不得改色） |
| 金額 | Readout 13px 等寬 `tabular-nums`；片長為假設時前綴 `≈` |

**紅線：** 語意色詞彙不得動 —— 綠＝正在發生、琥珀＝你要求了但沒發生。「未匹配」是
**中性灰**，不是琥珀：它不是一個「你要求了但沒發生」的狀態，是一個中繼資料事實。

## Pencil Inline AI Agent 提示詞（複製到 Pencil 執行）

> 更新 F15-D-v2（pwMzT）與 F15-M-v2（fdu4y）的候選列規格。所有變更沿用現有 token 與列型，
> 不新增任何設計 token、不改變版面骨架。
>
> **1. 封面**：列左側 38×54 的空灰方塊改為實際海報縮圖（2:3、圓角 sm、object-cover）。
> 另畫一個「無海報」變體：同尺寸 `--bg-tertiary` 灰塊，正中放片名首字，
> 18px / 600 / `--text-secondary`。
>
> **2. 副標改為兩段並列**：原本單行副標改為 `路線 · 片長`，中間以 ` · ` 分隔。
> 路線段為「內嵌英文字幕 → 翻譯」或「無文字字幕軌 → 語音辨識 + 翻譯」；
> 片長段在已知時為「2 小時 46 分」，未知時為「片長未知（估 45 分）」。
> 兩段永遠同時存在，不得互相取代。12px `--text-muted`。
>
> **3. 未匹配標**：在**片名右側**（不是右側徽章區）加一個中性灰標「未匹配」，
> 12px、`--bg-tertiary` 底、`--text-muted` 字、圓角 sm。片名過長時截斷片名，
> 此標不得被擠掉。只在 TMDb 沒比對到的列出現。
>
> **4. 資料夾無法寫入狀態**（sub-6-1 已上線但稿子沒有）：新增一個列變體 ——
> checkbox 為 disabled、整列 70% 透明度、右側徽章區最左側加一個 error tint 的
> 「資料夾無法寫入」標籤。
>
> **5. 群組 header**（sub-5-3 已上線但稿子沒有）：影集／季的群組標題列 ——
> 左側三態 checkbox（未選／半選／全選）、影集或季名稱、右側「已選 n/N」與選中小計金額。
>
> **6. F8 重試按鈕**（sub-5-3 已上線但稿子沒有）：在 F8 終局畫面的 footer 加一個
> 次要按鈕「重試失敗項目」，位置在既有「下次繼續」按鈕同一列。
>
> 右側徽章區的順序固定為：資料夾無法寫入 → 路線徽章 → 金額。
> 路線徽章語意色不得更動（抽取＝success tint、語音辨識＝warning tint）。
