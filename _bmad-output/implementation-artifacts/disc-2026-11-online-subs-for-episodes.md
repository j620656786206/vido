# Story disc-2026-11-online-subs-for-episodes：單集也能線上搜尋字幕，用原文片名＋第幾季去搜

Status: done

**Source:** sprint-status 同名待辦（P2，PR #971 留下）。⚖️ Alexyu 2026-11-02「接著做」。

## 問題

1. 管理字幕的「搜尋線上字幕」只開給電影和整部劇；單集看不到（後端 `oneof=movie series`，9R-10c 紅線 2 因此隱藏）。缺中文的幾乎都是劇集。
2. 查詢字是台灣片名（「天蠍行動」）。射手網收錄的是原文或大陸譯名，搜不到；「Scorpion S01」才搜得到。前端不送查詢字時，後端還會拿 media_id（一串 UUID）去搜。

## 做法

1. 後端搜尋／下載接受 `media_type=episode`（media_id＝集數 id）。
2. 請求沒帶查詢字時，後端自己組：
   - 電影：原文片名＋年份；
   - 整部劇：原文劇名；
   - 單集：原文劇名＋季數＋集數（`SubtitleQuery.Season/Episode`）。
   - 原文片名是日文假名／韓文時改用中文片名（射手網收中文譯名）；沒有原文就用中文片名。
3. 射手網：有季數時查「原文 S01」（整季包和單集都會出來，不加年份）。
4. 單集搜尋結果濾掉「別集」：檔名寫了別的 SxxEyy 就不列；整季包（沒寫集數、或 E01-E22 這種範圍涵蓋這一集）保留。
5. 單集下載成功 → 寫回這一集的字幕狀態；簡轉繁的「保留原用語」國別用所屬劇集的。
6. 前端：單集模式顯示「搜尋線上字幕」；搜尋不再送台灣片名，交給後端組。

4. [x] 管理字幕對話框在單集模式顯示線上搜尋，可搜、可下載。
5. [x] 測試；go／web 檢查全過；受影響的視覺基準更新。
