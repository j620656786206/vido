# Story disc-2026-11-subtitle-backup-no-clobber：取代字幕時不再蓋掉更早的備份

Status: done

**Source:** 2026-11-03 查 Alexyu 的「正常」測試紀錄時發現。

## 問題

放字幕時如果同名檔已存在，會先把它改名成 `.bak`。但 `.bak` 已經存在時會直接被蓋掉。《天蠍行動》S01E02：

1. 原本是付費 AI 生成的繁中字幕。
2. 16:23 第一次下載射手網字幕 → AI 字幕存成 `.bak`。
3. 22:20 第二次下載（測確認窗）→ 第一次下載的檔案改名成 `.bak`，**把 AI 字幕蓋掉了**。現在 `.srt` 和 `.bak` 一模一樣（md5 相同），AI 字幕已不在磁碟上。

## 做法

`.bak` 已存在時改用第一個空著的 `.bak.2`、`.bak.3`…（上限 999），永遠不覆蓋舊備份。`.bak` 是資料夾時維持原本的報錯。

## Acceptance Criteria

1. [x] 連續取代三次：`.bak` 是最原始的版本、`.bak.2` 是第一次下載、`.bak.3` 是第二次。
2. [x] 原有測試不變（`.bak` 是資料夾仍報錯、Cleanup 照舊）。
3. [x] go test、staticcheck 全過。

## Dev Agent Record

- 已遺失的 AI 字幕救不回來（檔案系統上已被覆蓋）；要的話只能重新生成。
